# กติกาผู้สังเกตการณ์

## ก่อนเริ่ม

- ตรวจ readiness และ test fixture ตาม [test-plan.md](./test-plan.md) และ [reset-checklist.md](./reset-checklist.md)
- อธิบายว่ากำลังประเมินระบบ ไม่ได้ประเมินความสามารถของผู้เข้าร่วม; การข้าม/หยุด task ไม่มีผลเสีย
- ขออนุญาตก่อนจดบันทึกหรือบันทึกภาพ/เสียง ระบุวัตถุประสงค์ ผู้ที่จะเข้าถึง และวิธีจัดเก็บ หากไม่ยินยอมให้ใช้การจดบันทึกแบบไม่ระบุตัวตนแทน
- ให้ผู้เข้าร่วมเลือกบัญชีทดสอบตาม role; อย่าขอรหัสผ่านจริงหรือให้เปิดเผย secret
- อ่านการ์ดตามตัวอักษร ห้ามอธิบายศัพท์ใน UI หรือแนะนำว่าจะเริ่มที่ใด

ข้อความชี้แจงที่ใช้ได้:

> เราต้องการดูว่าระบบช่วยให้คุณทำงานนี้ได้อย่างไร เรากำลังทดสอบระบบ ไม่ได้ทดสอบตัวคุณ กรุณาทำตามที่คุณเข้าใจได้เลย ฉันจะไม่บอกขั้นตอนระหว่างงาน แต่คุณหยุดหรือขอข้ามได้ทุกเมื่อ

## ระหว่าง task

- เริ่มจับเวลาเมื่ออ่านโจทย์จบ; บันทึกการกระทำตามลำดับพร้อมเวลาโดยไม่ตีความแทนผู้เข้าร่วม
- ไม่ชี้เมาส์ แตะจอ เลื่อนหน้าจอให้ หรือชี้ชื่อปุ่ม/แท็บ/เมนู
- ระหว่างการเดินจริง ให้เดินตามในระยะที่ไม่ชี้นำ บันทึกการถึงห้องและการเลี้ยวผิด ห้ามเร่งหรือพาผู้เข้าร่วมเข้าเขตปิด/ไม่ปลอดภัย; หากมีความเสี่ยงให้หยุด task ทันที
- ไม่ตอบคำถามเชิงวิธีใช้ด้วยคำใบ้ หากผู้เข้าร่วมถาม ให้ตอบเพียง “ลองทำตามที่คุณคิดว่าเหมาะสมได้เลย ฉันจะบันทึกจุดที่ติดขัดไว้”
- ถามได้เฉพาะคำถามเป็นกลาง เช่น “ตอนนี้คุณกำลังคิดอะไรอยู่” เมื่อผู้เข้าร่วมเงียบและยินยอมเล่าความคิด ห้ามถามนำ เช่น “เห็นปุ่มนำทางไหม”
- เมื่อได้รับการช่วยเหลือทางเทคนิคที่จำเป็นจากผู้จัด ให้หยุดเวลา บันทึกสาเหตุและการช่วยเหลือ และจัดผลว่าได้รับความช่วยเหลือ
- หยุดเมื่อผู้เข้าร่วมขอหยุด, มีความเสี่ยง/ข้อมูลผิดพลาดที่กระทบระบบจริง, หรือครบเวลาสูงสุด 15 นาทีต่อ task; บันทึกเหตุผลและห้ามตีความการหยุดเป็นความล้มเหลวของผู้เข้าร่วม
- ห้ามปล่อยให้ผู้ทดสอบส่งข้อมูลจริงหรือแก้ resource นอก fixture ที่กำหนด

## หลัง task

- ให้ผู้เข้าร่วมกรอกคะแนนและคำถามปลายเปิดใน [result-template.md](./result-template.md) ก่อนอธิบายเฉลยหรือสาธิต
- ทวนข้อสังเกตเชิงข้อเท็จจริงได้ แต่ไม่โต้แย้งหรือแก้คำตอบของผู้เข้าร่วม
- แยกคำพูดตรงจากการตีความของผู้สังเกตการณ์ และไม่บันทึกข้อมูลส่วนบุคคลที่ไม่จำเป็น
- ตรวจ reset ตาม [reset-checklist.md](./reset-checklist.md); ถ้า restore ไม่สำเร็จ ให้หยุด session ถัดไปและแจ้งผู้ดูแลระบบทันที
