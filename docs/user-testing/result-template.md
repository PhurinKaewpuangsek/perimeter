# แม่แบบแบบฟอร์มผลทดสอบผู้ใช้จริง V4

คัดลอกแบบฟอร์มนี้หนึ่งชุดต่อผู้เข้าร่วม และกรอกส่วน task แยกกันทุก task ใช้รหัสผู้เข้าร่วมในเอกสารที่อยู่ใน repo เว้นแต่มีการอนุญาตให้ใช้ชื่อจริงโดยชัดแจ้ง

## ข้อมูลผู้เข้าร่วมและ session

| รายการ | บันทึก |
|---|---|
| รหัสผู้เข้าร่วม | |

| Role ที่ทดสอบ (`student/user`, `staff`, `admin`, อื่น ๆ) | |
| วันที่และเวลาเริ่ม session | |
| ผู้ดำเนินการ / ผู้สังเกตการณ์ | |
| สภาพแวดล้อมและ build ที่ทดสอบ (dev test URL โดยไม่ใส่ token) | |
| อุปกรณ์ / OS / browser / ขนาดหน้าจอ | |

| หมายเหตุเรื่องการเข้าถึง/ข้อจำกัดอุปกรณ์ (ถ้ามี) | |

## คำถามหลัง task

ให้ผู้เข้าร่วมตอบเอง โดยไม่อธิบายหรือชี้นำ:

1. งานนี้ยากหรือง่ายเพียงใด? (1 = ยากมาก, 7 = ง่ายมาก): ___ / 7
2. คุณมั่นใจเพียงใดว่าห้องและเส้นทางถูกต้อง? (1 = ไม่มั่นใจเลย, 7 = มั่นใจมาก): ___ / 7
3. มีช่วงใดที่สับสนหรือต้องลองใหม่? ถ้ามี โปรดเล่า: ____________________
4. มีข้อมูลอะไรที่คุณอยากเห็นเพิ่มเพื่อทำงานนี้? ____________________
5. ความเห็นอื่น: ____________________
